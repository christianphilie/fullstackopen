# Full Stack Open 🚀

This repository contains my solutions and assignments for the [Full Stack Open](https://fullstackopen.com/en/) course by the University of Helsinki.

The course covers modern JavaScript-based web development, with a focus on building single-page applications (SPAs) with React and REST APIs built with Node.js and Express. 💻
